# AXM Infinite Fabric showcase system

The showcase is an executable product surface at `showcase.html`. It is not a slide deck and does not substitute mock data for the underlying systems.

The director materializes four real world revisions from the current Fabric runtime:

```text
root Tiny World
→ First Star collected through semantic action
→ north-village patch accepted
→ rain and bridge patch accepted
```

It then stages eight chapters:

```text
one world
one canonical revision across projections
structured MAKE proposal
accepted village materialization
real Classic Trials engine montage
world memory and restored seals
replaceable provider classes
provider-off and network-off custody
```

The world scenes consume real Fabric world objects. The MAKE chapter reads the actual structured village patch. The Classic Trials chapter runs the same deterministic Canvas engines used by the playable suite. The memory rail uses the actual world ledger and explicitly marked Classic Trial event projections. The provider and custody chapters state architecture and current runtime conditions without claiming that a cloud provider was invoked.

## Presenter controls

```text
Right Arrow    next chapter
Left Arrow     previous chapter
Space          play or pause
R              restart the sequence
C              clean capture mode
F              fullscreen
```

URL controls:

```text
showcase.html?autoplay=1&loop=1
showcase.html?autoplay=1&loop=0&clean=1
showcase.html?chapter=play-the-story
```

The start surface can enable generated Web Audio cues after a user gesture. No audio asset or external service is required.

## Capture pipeline

The dedicated workflow builds the complete product, executes a presenter-control transaction in Chromium, records a 1920 by 1080 WebM reel, captures six evidence plates, assembles a portable static package, computes an internal SHA-256 ledger, and uploads the package with browser receipts.

The capture remains held if TypeScript, the Fabric and Classic Trial substrate, production build, presenter transaction, browser console, page execution, video generation, screenshot generation, or package ledger verification fails.

## Evidence boundary

The showcase proves that the current source can assemble and execute a compelling deterministic narrative from actual world, game, patch, revision, and memory components. It does not prove live model generation, product-market response, human enjoyment, television calibration, MotionDeck operation, Quest acceptance, or final product acceptance.
