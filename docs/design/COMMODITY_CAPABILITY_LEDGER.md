# AXM commodity capability ledger

**Purpose:** prevent new model/tool capability from causing parallel reinvention. This ledger separates the current mainline product from qualified or partially qualified commodity lanes preserved on repository branches.

## Mainline substrate

Current `axm-world` main `2dffdf0` already contains the scarce part: deterministic Arc-derived play, portable run custody, generic representations, neutral cartridge fallback, and the complete Gate 7 clean-room receiver lineage. Gate 7 merged at `466ead0` and its entry-transition race was subsequently bounded at `d1f569e`.

Current `axm-arc` main remains the authority for authored simulation law. World Forge therefore consumes validated Arc records and `cart1_` identity; it does not migrate presentation-generation behavior into Arc.

The new World Forge layer on this change provides the missing generic front door:

```text
Arc law + cart1 digest
  -> provider-neutral production jobs
  -> GLB / PNG / governed SVG commodity products
  -> digest-bound expression pack
  -> independent local audit
  -> host-specific materializer or Rodoh integration
```

## Commodity producers now fit one contract

World Forge treats current and future production systems as interchangeable labor. A coding model driving Blender, a screenshot critic loop, image-to-model, procedural geometry, the existing UNDERDRAIN sprite-authoring console, project-authored SVG, licensed local art, or a human artist can all satisfy a slot when the returned bytes and receipts pass the same boundary.
The scarce invariant is the semantic slot and its source law. The producer implementation is replaceable. The host materializer is replaceable. Acceptance remains explicit.

## Convergence sequence

1. Keep the exact Gate 7 Orchard clean-room fixture neutral. Its proof is that an unknown cartridge works without bespoke art.
2. Use a different unbundled cartridge for expression-pack qualification. `deepway-rescue` is the first substrate proof because it already exists outside the first-party theme map.
3. Feed the same World Forge plan to multiple producer lanes and compare receipt-complete outputs rather than adopting a model/vendor schema.
4. Generalize the proven UNDERDRAIN local-authoring and Unity materializer transactions behind the World Forge slot contract.
5. Add a Rodoh-side expression-pack receiver only after the build-time pack and host-materializer paths prove that generated presentation can be replaced without changing `cart1_` or run results.
6. Preserve external-host/device seams such as MotionDeck and QuestStage as adapters around accepted simulation, not as alternate authorities.

That sequence lets falling model and asset-generation costs accelerate AXM without moving trust, game law, or creator custody into the commodity layer.
