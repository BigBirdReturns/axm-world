# AXM Infinite Fabric

QuickPlay is one creation ingress. Infinite Fabric is the persistent world substrate.

```text
QuickPlay
  prompt → sandboxed playable candidate

Infinite Fabric
  prompt → structured patch → preview → host acceptance
  → persistent world revision → memory ledger → offline replay
```

Canonical Fabric state is structured data. A generation provider may propose cells, entities, content-addressed assets, and references to versioned behavior schemas. It may not install arbitrary runtime code, change the world’s law authority, write directly to the memory ledger, or remain necessary after the accepted world is kept.

The First Charter Tiny World is the first Fabric world of record. Board, Map, Planet, and Play remain projections of one cartridge and one world revision. AXM-ARC owns accepted outcomes when `law.mode = arc`; the Rodoh receiver may render and collect semantic input but may not author those outcomes.

See `docs/INFINITE_FABRIC_V0.md` for the proving transaction and execution sequence.
