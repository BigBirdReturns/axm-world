# Infinite Fabric sprint stop condition

The current planning pass is complete when the repository contains:

```text
product lineage
world contract
patch contract
law boundary
alpha receipt schema
execution board
provider contract
world-context projection
release gates
public demo script
anti-drift rules
```

The next valid work is implementation of Gate 1 and Gate 2. Additional planning documents, schema classes, provider surveys, or evidence taxonomies do not advance the sprint until Tiny World movement, one ARC consequence, one structured patch, and offline persistence exist in the runtime.
