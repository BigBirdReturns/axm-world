# Infinite Fabric release gates

## Gate 0: recovered product boundary

Required:

```text
prior playable-world lineage recorded
QuickPlay classified as ingress
Fabric world and patch contracts present
The First Charter named as first world of record
anti-drift holds present
```

## Gate 1: Tiny World playable

Required:

```text
spherical or voxel planet movement
keyboard and gamepad semantic controls
Board, Map, Planet, and Play share one revision
one real encounter
one accepted ARC consequence
one visible world reaction
one append-only memory-ledger entry
offline reload
```

## Gate 2: structured generation

Required:

```text
prompt produces axm-infinite-fabric-patch/0
patch uses known behavior schemas
no arbitrary canonical code
no law change
no direct provider ledger write
preview before mutation
accept, refuse, undo, and branch
functional generated cell, NPC, and quest
```

## Gate 3: persistent revision

Required:

```text
second prompt changes existing behavior
previous revision remains recoverable
new consequence is visible across projections
export and clean-profile import pass
provider and network are absent during replay
```

## Gate 4: provider substitution

Required:

```text
two independent model providers
same bounded world-context input contract
same Fabric patch output contract
no provider-specific world conversion
accepted artifacts remain content-addressed
```

## Gate 5: fabric standing

Required:

```text
second world consumes the same contracts
second input or renderer adapter consumes semantic controls
no Tiny World implementation import in the second tenant
standalone contract qualification passes
```

Gate 5 is the earliest point at which the Fabric substrate may be considered for extraction from AXM-WORLD into a shared estate component.
