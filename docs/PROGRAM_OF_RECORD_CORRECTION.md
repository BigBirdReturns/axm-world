## Object 1: PROGRAM OF RECORD — Strategy

`PROGRAM OF RECORD — Strategy` is an existing game title and cartridge concept:

```text
AXM-WORLD • CARTRIDGE No. 03 • STRATEGY
PROGRAM OF RECORD
Convert advantage into inevitability before they turn your dependencies into evidence against you.
```

It is a playable two-to-four-seat defense-acquisition strategy game. Its canonical doctrines are:

```text
PRIME
  incumbent integration and institutional lock-in

NEO-PRIME
  venture challenge, demonstration velocity, and category breakthrough

DECENTRALIZED
  open architecture, interface control, interoperability, and no rival kill switch
```

Its existing mechanical spine includes a three-fiscal-year, twelve-quarter table; a forty-space institutional circuit; auctions, obligations, trades, teaming agreements, milestones, market pressure, and interference; Human, ROOKIE, PROGRAM MGR, and ADVERSARY seats; and Training Table, Normal Table, Knife Fight, and Circus presets.

The eight Program Actions are:

```text
Develop Evidence
Shape Requirement
Recruit Sponsor
Court Adoption
Build Sustainment
Set Standards
Harden
Run a Demo
```

The board's institutional control surfaces include JROC Seat, Requirements Office, Test Range, Cyber Range, PE Line, Reprogramming Authority, Depot Access, Supply Chain, Training Pipeline, Interface Standard, Reference Architecture, Congressional District, Service Sponsor, Coalition, Data Rights, Protest Counsel, and Standards Body.

The preserved standalone is a self-unpacking browser cartridge with a rules model and a combined engine/UI layer. It is an existing game body, not a roadmap, generic chapter factory, or name for The First Charter.

## Object 2: RODOH ProgramOfRecord registry

`src/world/program-of-record.ts` defines RODOH's controlled-program registry. It binds a cartridge's computed authored identity to its admitted runtime surfaces, entry experience, save schema, ledger schema, and extra asset identities. A manifest cannot claim this standing. The runtime derives it from the cartridge bytes.

The current registry contains:

```text
Program 001  The First Charter
Program 004  The Lamp District
Program 005  The Relief Circuit
```

Numbering gaps preserve accepted release lineage. A cartridge outside the registry remains playable as an ordinary holder-owned cartridge.

This registry is distinct from the game title `PROGRAM OF RECORD — Strategy`.

## Object 3: The First Charter

The First Charter is the first accepted RODOH program and a creator-owned cartridge. It has its own authored contracts, simulation law, representations, run state, ledger, and save identity. It is not synonymous with the `ProgramOfRecord` registry and it is not the strategy game titled `PROGRAM OF RECORD`.
