# Infinite Fabric sprint holds

Until The First Charter Tiny World completes the prompt-to-persistent-world transaction, the following work is held from the critical path:

```text
new general-purpose engine
unrelated prompt-to-game showcase
mandatory cloud identity
marketplace
multiplayer implementation
Quest-first implementation
Shape Field-first implementation
arbitrary generated code in canonical Fabric
provider-specific world or save format
model-authored ARC consequences
model writes directly to the memory ledger
regeneration that destroys an accepted branch
receiver-authored outcomes
new evidence ontology
```

The sprint accepts only work that directly advances one of these player-visible facts:

```text
The First Charter Tiny World is playable.
Board, Map, Planet, and Play share one world revision.
A prompt proposes a structured patch.
The player can preview, accept, refuse, undo, or branch.
The generated cell and entities are functional.
World reaction enters the memory ledger.
The world exports, imports, and reopens offline.
A second provider uses the same patch contract.
```

UNDERDRAIN, MotionDeck, ScreenGhost, Embodied-AR-Lab, Shape Field, ARC, and other estate systems remain available as bounded consumers or qualification lanes. None may redefine the first Fabric acceptance denominator.
