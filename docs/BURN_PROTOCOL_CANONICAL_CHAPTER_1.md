# The Burn Protocol canonical Chapter 1 receiver

## Classification

This transaction publishes the first Burn chapter as an Arc-governed canonical story. It does not summarize the chapter as challenges, derive a new governance scenario, create dialogue choices, found an organization, or present audit summaries as canonical text.

The authored extent is:

```text
Episode 1: The Broken Road
Chapter 1: Impact
E01-C1-P01 through E01-C1-P18
four scroll-plate assets
canonical continuation E01-C2-P19
```

## Authority chain

```text
burn-protocol/1 creator source
  → strict Arc source-plane validation
  → axm-canonical-story/1 fixed story graph
  → ordinary validated Arc with cart1_ identity
  → visible World cartridge import
  → canonical-story capability dispatch
  → SequenceHost before useArcWorld
  → digest-bound reading cursor
  → fixed panel traversal
```

Arc owns panel order, chapter boundaries, source receipts, asset receipts, text standing, fixed transitions, and transition receipts. World owns responsive projection, local file selection, temporary object URLs, and reading-position storage. World cannot add a panel, alter a successor, create a branch, or convert a development audit projection into canonical dialogue.

## Why `WorldHost` dispatches first

The existing simulation path begins by founding an `Organization`. That is correct for challenge-driven cartridges and false for a canonical chapter. `WorldHost` therefore reads `axm.canonical-story@1` before calling `useArcWorld`.

```text
canonical story present
  → SequenceHost

canonical story absent
  → SimulationWorldHost
      → useArcWorld
      → RuntimeRouter
```

The Chapter 1 Arc carries zero roles and zero challenges. Its three inert ABI attributes are a frozen compatibility host required by the current Arc schema. They are not displayed and own no story state.

## Current source boundary

Every Chapter 1 panel therefore carries:


Every plate carries:

```text

```

The reader shows no reconstructed dialogue, caption, sound effect, alt text, or guessed plate range. Q01/Q02-derived location, actor, and short summary fields may be displayed only under the explicit label:

```text
DEVELOPMENT AUDIT PROJECTION · NOT CANONICAL DIALOGUE
```

## Holder-controlled assets

The reader accepts local panel or plate files only after matching one manifest path, exact byte count, and SHA-256. Ambiguous basenames require the containing estate directory. A failed file causes the selected batch to be refused.

Verified image bytes receive page-session object URLs. They do not enter:

```text
Git
World static build
Arc content
localStorage
service-worker cache
portable simulation run
```

Reload releases the object URLs and requires file reselection. The reading cursor remains resumable under the exact Arc digest.
