A single-file, offline AXM authored-pilot candidate built from one cold creator premise:

> A municipal plumber is drafted into a secret war against the hidden fungus kingdom causing every drain problem in town.

The executable is one continuous authored and represented chain:

```text
Mrs. Kett service call
  -> represented kitchen, customer, plumber, living trap, and clean bypass
  -> inspect the living trap joint
  -> restore one household's water with zero hostile actors
  -> municipal draft and an authored Pump Seven entry method
  -> represented cast, institution, and three route marks
  -> inspect and reroute three living spore valves
  -> hold the purge wheel at shared-flow pressure
  -> balance the Crown Sluice
  -> exact Arc action acceptance
  -> represented town, relationship, evidence, and obligation changes
  -> represented playable Root Gate parley
  -> exact Arc compact acceptance
  -> represented complete episode record
```

Combat is pressure around the plumbing operation. Defeating a pressure actor cannot complete a valve, purge wheel, or sluice.

## Six required player surfaces

A first-party pilot is not machine-qualified merely because assets exist somewhere in the repository. The representation plan binds cartridge-owned assets to all six controlling surfaces:

1. cold entry;
2. authored commitment;
3. first action;
4. accepted consequence;
5. playable successor;

Every surface must pass on desktop and mobile and carry a nonvisual equivalent. Browser evidence identifies visible assets using `data-presentation-asset`; the action canvas records its active environment, player, mechanism, and pressure-actor identities in `data-representation-assets`.


## Persistence and custody

The standalone supports two explicit persistence modes.

When served from HTTP or HTTPS, the session uses browser-profile `localStorage`. Reload and later return use the same browser-origin record.

When opened directly from disk through `file:`, Chromium-family browsers do not provide a portable durable `localStorage` contract. Underdrain installs a namespaced `window.name` adapter before session boot. This preserves exact reload and resume in the current tab. Closing the tab ends the active direct-file session. The player surface states this boundary, and the complete episode record includes:

```text
persistence.mode = window-name
persistence.durability = current-tab
persistence.exactReload = true
persistence.closeTabRequiresExport = true
```

Use **Download episode record** before closing a direct-file tab when durable custody is required. The export retains the exact World, Arc, cartridge, authoring, representation, accepted action, compact, campaign, structural-evidence, and persistence identities.

Representation is installed before cold boot, resume, and the automated matrix. A saved action cannot render one schematic frame before the governed renderer takes control.

## Controls

- Move: `WASD` or arrow keys
- Work on the current mechanism: `E` or `F`
- Wrench: `J` or `Space`
- Dodge: `Shift`
- Mobile: visible directional, wrench, work, and dodge controls

The mobile geometry gate requires every touch control to:

- remain inside the action stage;
- provide at least a 44 x 44 CSS-pixel target;
- avoid overlap with every other control;
- remain separated from the objective ribbon.

The opening service call contains no enemies. Pump Seven introduces defenders as pressure around the plumbing operation.

## Classification and evidence boundary

The product classification is now conjunctive:

```text
structural authored-experience gate
AND candidate-bound representation gate
= machine-qualified authored pilot
```

Structural causality without production representation is an `authored-logic prototype`, not a machine-qualified pilot.

The executable emits structural evidence in `rodoh-one-am-structural-evidence/1` and representation evidence in `rodoh-representation-runtime-evidence/1`. It cannot certify that a blind human understood the experience. It therefore records:

```text
blindPlayerReceipt.status = not-issued-by-runtime
blindPlayerReceipt.required = true
```

An independent zero-assistance one-a.m. observation tied to the same exact World, Arc, cartridge, authoring, representation, and build identities is still required before calling it an accepted playable authored episode.
