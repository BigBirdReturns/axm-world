# AXM circulation convergence v1

**Status:** integration candidate. This document records the load-bearing contracts assembled on the circulation integration branches. It does not promote or delete historical product surfaces by itself.

The durable product is the circulation of authored authority, legal actions, state, expression requirements, holder custody, and evidence. A particular Board, Map, Hall, 3D world, model provider, materializer, or host application is a replaceable projection unless a separate runtime contract makes it authoritative.

```text
creator source / Codex
  -> registered source plane
  -> Arc authored law + cart1 identity
  -> explicit runtime family
  -> legal actions / executor / event stream
  -> projection manifest
  -> replaceable player surface + World Forge materializers
  -> player input
  -> authoritative executor
  -> ledger / consequence / terminal state
  -> run3 holder custody + receipts
  -> qualification evidence
```

Law flows down this chain. Evidence flows back up. Presentation and tooling circulate around the outside.
## Candidate pillars assembled here

1. **Arc runtime-family law.** `axm.runtime-family@1` makes execution-family selection authored and digest-bound. The current families are fixed canonical sequence, encounter simulation, and strategy board. Missing declarations remain legacy compatibility; future versions remain opaque custody and cannot fall through to another executor.
2. **Strategy Board executor.** The previous schema/enumeration scaffold now has a bounded deterministic executor and explicit ledger events. World still has no promoted Strategy Board host, so authored `strategy-board` cartridges fail closed here rather than entering the simulation shell.
3. **World runtime-host registry.** Runtime composition selects a compatible host from authored authority and capability. Concrete cartridge identity is not a routing mechanism.
4. **Projection manifest.** A runtime projects the contexts, verbs, interactables, perceptible state, required feedback, and terminal conditions that a player surface must carry. Presentation does not define those actions.
5. **World Forge v2.** Commodity producers receive projection requirements rather than raw fiction nouns. Generated assets remain presentation-only and receipt-bound.
6. **Scaffold circulation guard.** Production cannot depend on probe trees or route by concrete cartridge identity without an explicit hash-pinned exception and removal condition.
7. **Provider-neutral receipt boundary.** Harvested donor lessons now verify local-contained bytes independently of the donor product or materializer that discovered the pattern.
## What remains scaffold

The historical Board / Map / Hall / World switcher and EncounterShell remain valid projections for the encounter-simulation family. They no longer define the platform's universal meaning of play. First-party themes remain content. Direct Fever Ward and Fever Tide runtime-expression work remain probes. Donor branches remain evidence archives until their reusable mechanisms have independent homes.

The Strategy Board World host is deliberately absent. Arc can now express and execute that runtime family, but World must first receive an independent projection contract and prove a real strategy cartridge through it. Until then, explicit `strategy-board` selection returns an unsupported-host refusal.

## Drain and deletion gate for the old universal shell

The old shell can be drained only after each supported runtime family has a promoted host and at least two unrelated cartridges or fixtures exercise its generic contract. During shadowing, the old and replacement paths must agree on legal actions, authoritative event streams, terminal state, portable custody, and compatibility where they claim the same runtime law.

Excising a historical surface requires zero unique state or resolver authority in that surface, no production consumer that depends on its private shape, preserved migration/boot/resume paths for carried runs, green runtime-family and projection acceptance, a clean scaffold-circulation inventory, and retained Git/evidence history. Deleting a surface that changes `cart1_`, legal actions, ledger events, terminal state, or `run3_` recovery proves the pillar was not mature enough.
