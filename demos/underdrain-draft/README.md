# UNDERDRAIN: The Bloom Below

A complete single-file, offline AXM demo for a first-time creator idea:

> A municipal plumber is drafted into a secret war against the hidden fungus kingdom causing every drain problem in town.

## Run

Open `index.html` directly in a modern browser.

No account, installation, backend, asset host, font host, analytics, or network connection is required.

For a repository checkout, build the exact file first:

```text
node scripts/demos/build-underdrain-draft.mjs
```

Then open:

```text
local/underdrain-draft/index.html
```

## Controls

- Move: `WASD` or arrow keys
- Wrench: `Space` or click/tap the canvas
- Pressure hose: `E`
- Dodge: `Shift`
- Flush a cleared valve: `F`
- Mobile: visible directional and action controls

## What the demo proves

The browser surface combines:

1. an original series constitution and stable-character episode rail;
2. a causal A-plot/B-plot collision;
3. three authored player methods;
4. one deterministic 30 Hz top-down action state;
5. a terminal provisional receipt;
6. persistent narrative consequences and obligations.

The browser receipt deliberately says:

```text
authority: Arc replay required
campaignEffect: null
```

The standalone game does not grant itself final campaign authority.

## Source and output

- `source/` — reviewable fragments used to build the one-file product
- `authoring.json` — exact Arc-authored manifest
- `playtest.json` — nine-case deterministic playtest receipt
- `PLAYTEST.md` — cold-walk, balance iteration, and accessibility report
- generated `index.html` — complete executable demo; all CSS, JavaScript, narrative data, and procedural visuals are inline

## Story shape

The implementation borrows the durable production structure discussed for long-running ensemble comedy, not any protected characters, names, art, dialogue, or setting:

- stable character methods;
- an institution that treats absurd stakes seriously;
- an A-plot and B-plot that causally collide;
- escalation caused by choices rather than random spectacle;
- a legible hidden cause;
- no clean reset;
- persistent obligations that can drive a later episode.
