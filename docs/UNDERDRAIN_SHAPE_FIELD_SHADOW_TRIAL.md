## Refusal

The experiment is refused if it changes a collider or target, changes registration, changes the semantic action sequence, changes the accepted ARC receipt, introduces an unaccounted fallback, expands material or shader families, regresses the constrained device resource, or fails visual review. Refusal returns the surface to its ASTC, KTX2, raster, SVG, pixel, or MSDF lane without reopening the UNDERDRAIN product baseline.
