# Qualification evidence

Committed evidence is the local source/contract transaction used to publish v0.1.0. CI adds platform-specific selftest and native-build artifacts without rewriting these files.

```text
node-test.tap          dependency-free admission/refusal suite
selftest-receipt.json  bounded authenticated IPC transaction
source-check.json      syntax, JSON, SMAPI-boundary, source-pin, and symlink checks
qualification-receipt.json aggregate authority statement
```

No file in this directory represents a real Stardew, Quest, television, controller, or physical-player transaction.
