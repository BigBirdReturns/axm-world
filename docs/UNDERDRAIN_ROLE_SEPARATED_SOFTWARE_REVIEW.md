# UNDERDRAIN role-separated software review

The Windows software-product comprehension gate is staffed by four bounded functions rather than by a requirement to locate particular people. The first three functions create a review receipt. A fourth function may consume that receipt with the rest of the exact product evidence and issue bounded Windows software-product acceptance.

```text
cold player
  exact built product and ordinary player instructions only

cold observer
  immutable session capture and completed player packet only

cold adjudicator
  frozen contract, observer packet, and accepted ARC receipt only

product acceptor
  completed evidence bundle only, with no artifact-mutation capability
```

Every review function carries a distinct seat identifier, model or instrument lineage identifier, and context digest. Every function declares `candidateAuthor = false` and `artifactMutationCapability = false`. The player and observer receive no source, answer key, or acceptance rubric. The runtime and candidate-author lineage cannot issue the review receipt. The adjudicator may accept or refuse the software-review evidence, but it cannot accept an ARC consequence or the player product.

The review recorder recomputes the complete packet chain, exact World and ARC identities, Windows product digest, session digest, accepted ARC receipt, teach-practice-master objective completion, authored choice, canonical consequence, next playable action, assistance state, and voluntary continuation. Its output is:

```text
rodoh-underdrain-role-separated-review-receipt/1
```

The final product assembler requires a fourth seat whose identifier, lineage, and context are distinct from all three review functions and whose seat differs from the presentation-approval authority. Its output is bounded to:

```text
rodoh-underdrain-player-product-acceptance/2
scope = windows-software-player-product
```

Human play, accessibility observations, household use, mounted Quest use, and physical comprehension remain separately typed physical evidence. A cold-seat pass cannot be relabelled as human, household, Quest, or physical-installation acceptance. ARC remains the sole consequence authority, and the reviewed artifact cannot be modified by any review or acceptance function.

## Operator sequence

After the Windows product train and one accepted mechanic session exist, run `scripts/new-underdrain-role-separated-review-kit.ps1`. Instantiate the three review functions from distinct lineages and contexts, complete the packet templates and cited transcript, notes, and adjudication objects, and recompute every SHA-256 field. Run `scripts/record-underdrain-role-separated-software-review.ps1` to issue the review receipt. After both required device sessions have passed, use a fourth independent acceptance seat with `scripts/accept-underdrain-player-product.ps1`.

Failed evidence remains immutable. Correct the first divergent packet, identity, digest, authority, or observation plane and issue a new transaction rather than rewriting the failed record.
