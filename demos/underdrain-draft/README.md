# UNDERDRAIN: The Bloom Below

UNDERDRAIN is a single-file, offline authored-pilot candidate built from the original premise:

> A municipal plumber is drafted into a secret war against the hidden fungus kingdom causing every drain problem in town.

The candidate is mechanically continuous rather than a story wrapper around an enemy-clear prototype. Its opening service call has no hostile actors. Rhea inspects a living trap joint and holds a household bypass until Mrs. Kett's water returns. Pump Seven then places combat pressure around three explicit mechanisms, but defeating pressure actors does not complete the plumbing objectives. The player must diagnose the valves, operate the purge wheel, and balance the Crown Sluice. Every Pump Seven outcome opens an implemented Root Gate parley.

## Build and run

The source fragments are assembled into one dependency-free HTML file. The build must be bound to the exact World candidate being qualified:

```text
node scripts/demos/build-underdrain-draft.mjs \
  --root demos/underdrain-draft \
  --output local/underdrain-draft/index.html \
  --world-commit <40-character-world-commit>
```

Open `local/underdrain-draft/index.html` directly in a modern browser. The file requires no account, backend, installation, asset host, font host, analytics endpoint, or network connection.

## Controls

- Move: `WASD` or arrow keys
- Work on the current mechanism: hold `E` or `F`
- Wrench: `J`, `Space`, click, or tap
- Heavy wrench: `K`
- Dodge: `Shift`
- Parry: `L`
- Mobile: visible directional, dodge, wrench, and work controls
